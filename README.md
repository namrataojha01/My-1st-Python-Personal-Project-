# Customer Shopping Behavior Analysis

## About

I used Python to analyze customer shopping behavior using a Kaggle dataset.

The dataset has 3,900 records and 19 columns.

## What I Did

- Checked and cleaned the data
- Checked missing values and duplicates
- Created new columns like Age Group and Estimated Annual Spend
- Performed EDA using different charts
- Analyzed purchase amount, category, gender, discount, payment method and frequency
- Created customer value segments based on estimated annual spending

## Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn

## Key Finding

High-value customers had higher purchase amounts and purchase frequency compared to other customer groups.

## Dataset

Dataset downloaded from Kaggle for learning and portfolio purposes.
